## SERP Feature Targeting Matrix

| Feature | Content Type | Schema Required | Page Type |
|---------|-------------|-----------------|-----------|
| Featured Snippet (paragraph) | Definition/explanation | None (content format) | Landing/Blog |
| Featured Snippet (list) | Step-by-step / Top N | HowTo / ItemList | Blog/Guide |
| Featured Snippet (table) | Comparison data | Table markup | Comparison |
| FAQ Rich Result | Q&A pairs | FAQPage | Landing/Feature |
| How-To Rich Result | Step instructions | HowTo | Blog/Guide |
| Product Rich Result | Product info | Product/SoftwareApplication | Landing |
| Review Rich Result | Aggregate reviews | AggregateRating | Landing |
| Sitelinks | Major pages | WebSite + good structure | Homepage |
| Video | Video content | VideoObject | Any |
| Breadcrumbs | Navigation path | BreadcrumbList | All |

## Review Platform Strategy

### Profile Optimization Checklist
For each review platform (Capterra, G2, GetApp, etc.):
- [ ] Complete all profile fields (100% completion)
- [ ] Keyword-optimized product description
- [ ] High-quality screenshots (annotated, showing key features)
- [ ] Video demo uploaded
- [ ] All features/categories properly tagged
- [ ] Pricing information current
- [ ] Integration list complete
- [ ] Comparison data accurate
- [ ] Review response rate > 90%
- [ ] Regular profile updates (monthly)

### Review Generation Framework
1. Identify satisfied customers (NPS > 8)
2. Time request after positive support interaction or milestone
3. Provide direct links to specific review platforms
4. Diversify across platforms (don't stack one platform)
5. Respond to ALL reviews (positive and negative) within 48 hours
