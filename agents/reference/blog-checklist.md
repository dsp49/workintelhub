# How to Use This Document
This is the complete review framework for every blog article published on timechamp.io. It covers all six blog types used in the Time Champ content strategy. Each type has a universal section (applies regardless of type) plus a dedicated type-specific checklist that addresses its unique structure, intent, and conversion requirements.

### Step-by-step review process
- Identify the blog type using the Blog Type Identification Matrix (next page). Write the type code (EG, CB, CA, PL, TB, CP) on the scorecard.
- Complete the Universal Checklist (Section U) — this applies to all six types.
- Complete the Type-Specific Checklist for the identified blog type.
- Run the AI Cliché Check (Section 9). Apply deductions to the Universal score.
- Total the score. Compare to the grade table. Log on the Scorecard page.

### CTA placement rules for all blog types
- TOFU blogs (cluster, guides): Max 2 CTAs — mid-article (after pain) and end. Soft discovery language.
- MOFU blogs (alternatives, comparison lists): 3 CTAs — after table, in TC section, end. Medium friction.
- BOFU blogs (calculators): 4+ CTAs — below calculator result, after limitations, after TC bridge, end. Hard conversion language.
- Template blogs: Download CTA first, then TC upgrade CTA after limitations. Two distinct CTA types.

- Never place two CTAs back-to-back with no content between them — reads as desperate
- Never use homepage as CTA destination — always link to: /free-trial, /demo, or a specific feature page
- CTA button copy must be specific: what will I get + how long will it take + what's the friction?

## Priority internal link rules for blogs
- Every blog must link to at least one TC feature page — this is non-negotiable for topical authority flow
- Calculator pages must link to: the relevant feature page + /free-trial or /demo — always
- Competitor alternative posts must link to the TC competitor comparison page if it exists

# Appendix B — Quick Reference & Minimum Publish Standards
## Minimum scores required before publishing

## Review frequency by blog type
- Calculator BOFU pages: Review every 3 months — inputs, TC features, and results language
- Competitor alternatives: Review every 4 months — competitor pricing and features change constantly
- Comparison lists: Review every 4–5 months — tools enter and exit the market frequently
- Comprehensive guides: Review every 6 months — check stats, update TC feature references
- Template blogs: Review every 6 months — ensure download links still work
- Cluster blogs: Review annually — or when the parent pillar page is updated

## Tools for blog review
- Grammarly Business — grammar, passive voice, tone analysis
- Hemingway Editor (hemingwayapp.com) — readability, sentence length
- Google People Also Ask — validate FAQ questions for AEO
- Ahrefs / Semrush — content gap analysis, competitor word count benchmarks
- Screaming Frog — broken link detection, internal link audit
- Google Search Console — check indexation, impressions, CTR on published blogs
- Google Rich Results Test — validate schema for all blog types
- schema.org/SchemaApp — advanced schema debugging
- ChatGPT / Perplexity — test: 'Ask AI' about the topic and see if your content is cited
- timechamp.io sitemap — check for cannibalization before publishing any new page
