# Time Champ Internal Linking Reference (Source of Truth)

Use this file to select internal links for all content. Links MUST be semantically relevant to the content topic per Koray Gubur's principles. Never link randomly.

---

## Semantic Linking Rules

1. **Every link must serve a semantic purpose.** The linked page must share at least one entity or attribute with the sentence where the link appears.
2. **Anchor text must be entity-rich.** Use descriptive phrases that name the entity, not "click here" or "learn more."
3. **BOFU pages link to other BOFU pages.** Feature pages link to related feature pages, solution pages, and comparison pages. Solution pages link to the feature pages that solve the problem. Comparison pages link to the TC feature pages referenced in the comparison.
4. **TOFU/MOFU blogs link to BOFU pages.** Blog posts should always link to the most relevant feature page(s) and solution page(s) for the blog's topic. Also link to related blog posts that deepen a subtopic.
5. **Use glossary links sparingly.** Link to glossary terms only when the term is first introduced and the reader may not know the definition.
6. **Link to case studies when claiming results.** If the content references business outcomes, link to a relevant case study.
7. **Minimum 3 internal links per page, maximum 10.** More than 10 dilutes link equity.
8. **Distribute links across the page.** Do not cluster all links in one section.
9. **Never link the same URL twice on a page.**
10. **Link to alternatives blog posts from comparison pages and vice versa.**

## SEMANTIC LINKING MATRIX (Which Pages Link to Which)

### For Blog Posts (TOFU/MOFU)
- Link to 1-2 **feature pages** most relevant to the blog's central entity
- Link to 1 **solution page** if the blog addresses a use case or problem
- Link to 2-3 **related blog posts** that go deeper on subtopics mentioned
- Link to 1 **glossary term** if a technical term is introduced
- Link to 1 **case study** if citing business outcomes
- CTA links go to **/signup** or **/book-demo**

### For Feature Pages (BOFU)
- Link to 2-3 **other feature pages** that complement this feature
- Link to 1-2 **solution pages** that use this feature
- Link to 1-2 **blog posts** that explain the concept in depth
- Link to 1-2 **comparison pages** where this feature differentiates TC
- Link to 1 **case study** if available for this feature

### For Solution Pages (BOFU)
- Link to 2-3 **feature pages** that power this solution
- Link to 1-2 **other solution pages** for adjacent problems
- Link to 1-2 **blog posts** that educate on the problem space
- Link to 1 **industry time tracking page** if industry-specific

### For Comparison Pages (BOFU)
- Link to 3-4 **feature pages** referenced in feature comparison
- Link to 1 **alternatives blog post** for the same competitor
- Link to 1 **solution page** relevant to the comparison context
- Link to **/pricing-usd** when discussing pricing

### For Alternatives Blog Posts (MOFU/BOFU)
- Link to 1 **comparison page** for the same competitor (TC vs X)
- Link to 2-3 **feature pages** that differentiate TC
- Link to 1 **solution page** relevant to the use case
- Link to **/pricing-usd** when discussing pricing
